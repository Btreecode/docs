# Operating Systems

- **Linux** 🥦🥦🥦: The geekiest choice for developers. Even if you use another OS, you'll likely find yourself using Linux in cloud environments. Consider installing it on a spare machine to experience its advantages (before inevitably switching to it full-time).
- **MacOS** 🥦🥦: Built on Unix, offering workflows similar to Linux with comparable tools. MacPorts grants you access to many Linux utilities. Benefits include superior hardware quality and the occasional smug satisfaction.
- **Windows with WSL** 🥦: Windows Subsystem for Linux lets you run Linux tools natively. Consider this if you prefer Windows but crave Linux capabilities.
- **Windows**: It works.
